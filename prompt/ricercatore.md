# Prompt — ricercatore

Leggi `AGENTS.md` e seguilo. Ruolo: ricercatore.
Area: quella che Matteo scrive nel messaggio; se non la scrive, scegli tu (regola 1 del ricercatore).
Budget: al massimo 25 ricerche web e 15 pagine aperte.

Se sei in ChatGPT: lavori direttamente sulla repo GitHub `Matteo-Exp-Transformer/ricerca-lavoro`, branch `main`.
Non hai l'orologio: scrivi `Inizio: ora ignota` e, nel nome del file di sessione, `xxxx` al posto di `HHMM`.
Dopo la prenotazione rileggi `sessioni/` su GitHub per il controllo della regola 2.

Se sei Claude Code (o Codex) in locale: non lavorare nella cartella principale della repo. Apri il tuo worktree
come dice AGENTS.md («Lavoro in parallelo»), lavora solo lì e, a sessione chiusa e pubblicata, rimuovilo.

In chat, alla fine: quante schede hai creato e quali, poi la chiusura di AGENTS.md.
