# ricerca-lavoro

Repo privata: sistema documentale per agenti (Claude, ChatGPT, Codex) che cercano e analizzano opportunità di lavoro per Matteo Cavallaro.

- `AGENTS.md` — regole per ogni agente (ingresso unico; `CLAUDE.md` lo richiama)
- `CHI_SONO_Matteo.md` — contesto professionale (copia unica, dal 12/11/2026)
- `opportunita/` — una scheda per opportunità (`azienda--ruolo.md`)
- `sessioni/` — un file per sessione di agente, scritto solo da chi lo crea
