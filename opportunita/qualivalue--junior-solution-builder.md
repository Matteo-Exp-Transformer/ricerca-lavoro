## Analisi
Analista: Claude Code desktop (Opus 5.5), 2026-11-12.
Pesi del §6: regge remoto, IA ([I] consulenza IA; [F] «modern development practices»), autonomia ([F] «Good organizational autonomy when working remotely»), requisiti raggiungibili (junior, nessun titolo richiesto), [I] imparare su progetti veri ([F] «interest in growing on concrete projects»). Persone poche (lavoro tecnico). Part-time [?]. Ne regge 4–5.

Requisito → esito
- Ragionare per componenti, flussi, dati → soddisfatto: definire requisiti e workflow (§5 Prodotto).
- Capire com'è fatta una soluzione software, anche semplice → soddisfatto: costruisci web app funzionanti, deploy su Vercel, Supabase (§5 Software con IA).
- Scomporre problemi complessi in attività tecniche verificabili → soddisfatto: sistemi multi-agente con guardrail (§5 IA/agenti); caccia alle falle (§5 Prodotto).
- Valutare in modo critico soluzioni generate → soddisfatto: [I] è il tuo uso quotidiano dell'IA con revisione incrociata; §5 IA/agenti.
- Precisione su risultati, casi limite, errori → soddisfatto: anticipare gli errori dell'utente (§5 Prodotto).
- Contribuire a sviluppo, refactoring, integrazioni → soddisfatto in parte: con l'IA sì (§5 Software con IA); «codice complesso da zero senza IA» è «Non dirlo».
- Plus: esperienza personale con web app e automazioni → soddisfatto (§5 Software con IA).

Potenziale: [I] è uno dei pochi annunci che chiede proprio il tuo modo di costruire: guidare e verificare soluzioni generate, non scrivere codice a memoria. Ti darebbe esperienza su progetti di clienti veri.
